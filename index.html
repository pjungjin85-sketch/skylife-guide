Q&A대응
기존 폰 그대로 쓸 수 있나요?
네, 현재 사용 중인 단말기에 유심만 교체하면 됩니다. 단, 기존 통신사에 단말기가 잠금(락)되어 있는 경우 해제가 필요합니다.
지금 위약금 있으면 어떻게 되나요?
위약금은 기존 통신사에 고객님이 직접 납부하시는 부분입니다. 저희 요금제 절감액과 비교해서 결정하시면 됩니다. 고객센터(114)로 잔여 위약금 확인 도움드릴게요.
데이터 다 쓰면 어떻게 되나요?
기본 데이터 소진 후에는 속도가 줄어들거나(QoS) 데이터 차단이 됩니다. 요금제별로 다르며, 추가 데이터 구매도 가능합니다.
해외에서도 쓸 수 있나요?
로밍 서비스는 별도 신청이 필요합니다. 고객센터를 통해 로밍 요금제 안내를 받으시도록 안내해 드립니다.
약정이 있나요?
약정 및 위약금이 없습니다. 언제든지 자유롭게 변경 또는 해지 가능합니다.
